# Ninja-Alley-Game
2D Game, 2 Player fighting game. Made with Unity. The player who kills another player wins.  

## How to Play
[Play in browser on itch.io](https://wasuphon-chaosahnguan.itch.io/ninja-alley)  

## Controls
- Player 1: A, D(Move), W(Jump), Spacebar(Attack), Q(Shield), E(Damage)  
- Player 2: ←, →(Move), ↑(Jump), Enter(Attack), ↓(Shield), Left Shift(Damage)  

## Built With
- Unity
- C#
